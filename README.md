# Veyra website

Public landing page for the Veyra Forever addon suite at [veyra.rschwab.nl](https://veyra.rschwab.nl/).

## Local preview

Run `python3 -m http.server 8000` and open `http://localhost:8000/`.

## Deployment

Publish `index.html`, `style.css` and the `assets/` directory to the `veyra.rschwab.nl` document root. The site needs only a static web server and HTTPS.

## Images

The World of Warcraft: Forever logo comes from [Blizzard](https://news.blizzard.com/en-us/article/24301453/everything-announced-at-blizzcon-2026-opening-ceremony). The three gameplay images show Veyra running in World of Warcraft: Forever. The Veyra mark is original to this site.

## ForeverDB

[ForeverDB.net](https://foreverdb.net/) is a planned source of game data to enrich the existing Veyra Forever addon. Potential uses include item details in tooltips and quest locations in the quest tracker or navigation. Keep a visible source link wherever ForeverDB data is displayed.
